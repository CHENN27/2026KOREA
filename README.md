## 功能簡介

### 📅 行程管理
- 多日行程規劃，支援拖曳排序
- 主卡片即時顯示選中日期的下一個行程與導航
- 一鍵開啟 Naver Map 導航（支援步行、地鐵、計程車）
- 天氣預報整合 + 穿搭建議

### 💰 旅行記帳
- 支援韓元 / 台幣 / 日圓等多幣別
- 自動匯率換算
- 速記模式快速記帳
- 多人分帳結算

### 🗣️ 旅行韓語
- 依情境分類的常用韓語句子
- 一般敬語 / 最高敬語切換
- TTS 語音播放（可調語速）
- 全螢幕展示模式，方便給店員看

### 🔒 出遊安心卡
- 住宿韓文地址一鍵顯示
- 緊急聯絡資訊（安全碼保護）

### ☁️ 雲端同步
- Firebase 即時同步
- 多裝置共用同一份行程
- 分享連結邀請共編

## How to Use

### 快速開始

1. 直接用瀏覽器打開 `index.html`，或部署到任意靜態伺服器
2. 手機建議「加入主畫面」以 PWA 方式使用，體驗最佳
3. 首次使用會以 localStorage 儲存資料；登入後可開啟雲端同步

### 日常使用流程

1. **切換日期** — 點選上方日期列切換要查看的天數
2. **新增行程** — 在行程管理頁點「＋新增」填入時間、地點、備註
3. **導航** — 點行程卡片的「Naver Map 導航」直接跳轉地圖
4. **記帳** — 切到記帳頁，點「記一筆」或「⚡速記」
5. **韓語查詢** — 切到韓語頁，選情境分類，點喇叭播放發音

### 開發

```bash
# 安裝依賴
npm install

# 開發時即時編譯 Tailwind CSS
npm run watch:css

# 產出最終壓縮版 CSS
npm run build:css
```

## 技術架構

- **前端框架**：Vue 3（CDN global build）
- **樣式**：Tailwind CSS 3
- **後端 / 同步**：Firebase Auth + Firestore
- **PWA**：Service Worker + Web App Manifest
- **圖示**：Lucide Icons
- **無需打包工具**，純靜態部署即可運作
